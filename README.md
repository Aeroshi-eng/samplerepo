# Aeroshi - Personal Portfolio Website

Welcome to my personal portfolio website!

This is a beginner-friendly web development practice project
created to improve my HTML, CSS, JavaScript and GitHub skills.

## About the Project

This website introduces me, showcases my technical skills,
displays sample projects and provides a contact form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Features

- Responsive navigation bar
- Personal introduction
- About Me section
- Technical skills section
- Project showcase
- Dark and Light mode
- Mobile navigation menu
- Contact form with validation
- Local storage for theme preference
- Scroll to top button
- Dynamic copyright year

## How to Run the Project

1. Clone this repository.

2. Open the project folder in Visual Studio Code.

3. Open index.html.

4. Run using Live Server.
